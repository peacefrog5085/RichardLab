# RichardLab π Forensics

This drop-in module adds a reproducible π identity experiment to RichardLab.

It tests a fixed matrix of:
- birthday digit strings
- A1Z26 name encodings
- padded A1Z26 encodings
- ASCII decimal encodings
- predetermined name/date concatenations

It deliberately does **not** accept or store Social Security numbers.

See `docs/pi_forensics.md` for setup and interpretation.
