# RichardLab Experiment: Personal Digit Strings in π

## Experiment ID

PI-FORENSICS-200M-001

## Question

Do predetermined finite digit encodings derived from a birthday and name occur
within the first 200,000,000 fractional digits of π, and where do their first
occurrences appear?

## Null Model

For statistical interpretation, decimal digits are treated as approximately
independent and uniformly distributed under the simple iid digit model.

This is a null model for assessing surprise. It is not a proof that π is
random or normal.

## Corpus

- Digits: 200,000,000
- Fractional digits only
- Position 1 = first digit after the decimal point
- Chunk size: 1,000,000
- Corpus generated using Chudnovsky binary splitting
- Corpus verification: OK

## Predetermined Candidate Matrix

1. Full birthday, decimal
2. Birth year, decimal
3. Month/day, decimal
4. First name, A1Z26
5. Last name, A1Z26
6. Full name, A1Z26
7. First name, padded A1Z26
8. Last name, padded A1Z26
9. Full name, padded A1Z26
10. Birthday followed by name
11. Name followed by birthday
12. Birthday followed by padded name
13. Padded name followed by birthday
14. First name, ASCII decimal
15. Last name, ASCII decimal

No SSN or other sensitive identifier was used.

## Pilot

A 10,000,000-digit pilot was performed before the 200M run.

Pilot observations:

- 0121: first occurrence at position 6,304
- 1981: first occurrence at position 15,176
- 01211981: not found within 10M

## Main Result

The complete 8-digit birthday sequence:

01211981

was found at position:

108,560,402

The shorter component sequences were found at:

0121  -> 6,304
1981  -> 15,176

The remaining name-based and combined long encodings were not found
within the 200,000,000-digit corpus.

## Statistical Interpretation

For a predetermined 8-digit sequence under the iid uniform-digit model:

Expected waiting scale ≈ 10^8 digits.

Observed first occurrence:

108,560,402 digits.

Approximate cumulative probability by the observed position:

66.23%.

Probability of at least one occurrence within 200,000,000 digits:

approximately 86.5%.

Therefore the observed birthday hit is compatible with the null model and
does not provide evidence that π encodes, predicts, or knows the person's
identity.

## Conclusion

The experiment successfully demonstrated that the predetermined birthday
encoding 01211981 occurs within the first 200M fractional digits of π.

Its occurrence position is consistent with the expected behavior of a
long digit sequence under the stated null model.

The result is therefore evidence of substring occurrence, not evidence of
personal information being intrinsically encoded in π.
